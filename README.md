# TwinTrades releases

Official Windows installers for **TwinTrades**, from ZoneNotice LLC. This repository holds installers only. It contains no source code.

**Download:** see [Releases](../../releases/latest) and download `TwinTrades-Setup-<version>.exe`.

## Check your download

Each installer's SHA-256 is listed in its release notes and on the TwinTrades website's download page. In PowerShell:

```powershell
Get-FileHash "TwinTrades-Setup-<version>.exe"
```

If the hash doesn't match, don't run the installer. Only download TwinTrades from this page or from the TwinTrades website.
